# 똑똑똑 (Knock) — iOS

매일 안전 체크인 · 비상 연락 · 가족 안부 · 건강/스트레스 통계를 제공하는 iOS 앱입니다.
Figma 시안(`제목 없음 9.15`)을 SwiftUI로 구현했습니다.

## 요구 사항

- Xcode 16 이상
- iOS 17.0 이상 (iPhone)

## 실행

1. `Knock.xcodeproj` 를 Xcode로 엽니다.
2. `Knock` 스킴을 선택하고 iPhone 시뮬레이터에서 실행합니다.

커맨드라인 빌드: `./scripts/build_sim.sh` (Xcode 27 RC가 설치되어 있으면 자동 사용, `SIM_DEVICE` / `SIM_OS` 로 대상 변경)

외부 의존성은 없습니다. 소스는 `Knock/` 폴더 기준으로 Xcode가 자동 동기화합니다.

## 데모 계정 / 동작

현재 백엔드 없이 `MockAuthService` 로 동작합니다.

| 항목 | 값 |
| --- | --- |
| 이메일 / 문자 인증번호 | `123456` |
| 아이디 로그인 | 아무 아이디 + 4자 이상 비밀번호 |
| 소셜 로그인 | 버튼 클릭 시 즉시 로그인 |
| 가족 초대 코드 | `1234-5678` (아버지), `8765-4321` (할머니) |

홈 화면 우측 하단 마법봉 버튼에서 **체크 완료 / 위험 감지(카운트다운 → 비상 연락) / 비상 연락 진행중 / 가족 응답 완료 / 가족 실시간 이벤트** 시나리오를,
건강 탭 우측 하단 버튼에서 **건강 상태 양호 ↔ 이상** 전환을 바로 시뮬레이션할 수 있습니다.

### Mock 으로 동작하는 기능

- **알림 센터** — 헤더 벨 아이콘, 미확인 배지. 체크인·위험 감지·가족·건강 연결 이벤트가 자동으로 알림을 생성하고 로컬에 저장됩니다.
- **체크인** — 기분 선택 → 연속 출석 일수 누적 + 축하 파티클, `내 체크인 캘린더` 에서 월별 기록 확인.
- **비상 연락** — 1순위 미응답 → 다음 연락처 응답 → `가족 응답 완료` 종료 화면. 다음 시도 카운트다운은 `AppState.nextAttemptDate` 기준.
- **가족** — 초대 코드 검증(오류 시 흔들림), 채팅 자동 응답 + 입력중 표시, 구성원별 전화번호, 실시간 활동 이벤트.
- **건강** — 건강 앱 연결 상태(`disconnected → connecting → connected`), 연결 시 실시간 심박수, 날짜별로 달라지는 수면/심박/스트레스 데이터와 그려지는 차트, 1분 호흡 운동 화면.
- **통계** — 주/월/년 이동 시 데이터와 요약이 함께 바뀌고 막대가 애니메이션으로 채워집니다.

## 구조

```
Knock/
├─ App/            진입점, 전역 상태(AppState), 라우팅
├─ DesignSystem/   색상·타이포·공용 컴포넌트(버튼, 입력, 헤더, 탭바)
├─ Models/         도메인 모델
├─ Services/       Auth / 알림 / 로컬 저장 (Mock 구현)
├─ Features/
│  ├─ Splash, Onboarding
│  ├─ Auth/        소셜·아이디·휴대폰 로그인, 이메일 가입, 아이디/비밀번호 찾기
│  ├─ Home/        체크인, 위험 감지, 비상 연락, 가족 지도, 안전 확인 팝업, 알림 센터, 체크인 캘린더
│  ├─ Stats/       스트레스 주기/월기/년기 통계
│  ├─ Health/      건강 총괄, 수면·심박·스트레스 상세, 호흡 운동, 건강 앱 연동
│  ├─ Family/      가족 목록·상세·체크인 캘린더, 초대, 채팅, 활동 기록
│  └─ Settings/    내 정보, 아이디/비밀번호 변경, 비상 연락처, 체크인·알림 설정, 권한, 탈퇴
└─ Assets.xcassets 시안에서 추출한 일러스트/아바타
```

## 후속 연동 지점

- `AuthServicing` — 실제 인증 API
- `NotificationScheduling` — 서버 푸시
- `HealthView` 의 Apple Watch 카드 — HealthKit
- `FamilyMapCard` — 실시간 위치 공유
